# Definition of Done

**Todo cambio**

- [ ] Sigue `AGENTS.md` y la checklist
- [ ] Compila sin warnings ni errores de analyzer nuevos, comprobado por herramienta
- [ ] Lo testeable tiene tests, y los relacionados pasan
- [ ] Un bug fix trae un test que falla sin el fix
- [ ] Sin código sin uso ni logs de depuración

**Cambios de UI**

- [ ] Textos localizados (o en inglés si no hay sistema)
- [ ] Pantalla nueva con su check en Play mode
- [ ] Prefab dejado a una persona con handoff completo
- [ ] Layout adaptado a las resoluciones objetivo
- [ ] Suscripciones, tokens y Addressables limpiados

**Antes de release**

- [ ] Probado en iOS y Android, con IL2CPP
- [ ] Memoria y frame rate revisados en dispositivos
