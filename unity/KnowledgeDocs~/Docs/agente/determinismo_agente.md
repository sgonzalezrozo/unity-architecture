# Herramientas antes que criterio

| ID | Regla |
|---|---|
| `DET-01` | Si un compilador, analyzer, test, script o generador puede decidirlo, se usa esa herramienta |
| `DET-02` | Una afirmación sobre el código sale de un resultado de herramienta, no de memoria. Si nada lo comprueba, se reporta como **no verificado** |
| `DET-03` | El trabajo mecánico repetido se convierte en script o generador |
| `DET-04` | Una regla comprobable se convierte en analyzer o test, no solo en una frase |

> [!RULE] EDIT-01
> "Compila", "pasa los tests" o "funciona" solo valen si lo dijo una herramienta.
