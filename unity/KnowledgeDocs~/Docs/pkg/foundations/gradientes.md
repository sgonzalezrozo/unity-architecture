# UI Foundations: gradientes de grupo

`UIGradientGroup` pinta **un** gradiente sobre varios `Graphic`, como si fueran una sola forma.

- El gradiente y el ángulo se ponen en el **padre**.
- Un hijo se excluye con `IgnoreGroupGradient`.

> [!NOTE]
> Es apariencia del prefab: se ajusta en el prefab, no desde una View (`PREFAB-04`).
