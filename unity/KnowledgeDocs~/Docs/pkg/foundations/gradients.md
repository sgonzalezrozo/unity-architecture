# UI Foundations: group gradients

`UIGradientGroup` paints **one** gradient across several `Graphic`s, as if they were a single shape.

- Set the gradient and angle on the **parent**.
- A child opts out with `IgnoreGroupGradient`.

> [!NOTE]
> It's the prefab's look: set it in the prefab, not from a View (`PREFAB-04`).
