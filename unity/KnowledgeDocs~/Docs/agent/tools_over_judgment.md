# Tools over judgment

| ID | Rule |
|---|---|
| `DET-01` | If a compiler, analyzer, test, script or generator can decide it, that tool is used |
| `DET-02` | A claim about code comes from a tool result, not memory. If nothing can check it, it's reported **not verified** |
| `DET-03` | Repeated mechanical work becomes a script or generator |
| `DET-04` | A checkable rule becomes an analyzer or test, not only a sentence |

> [!RULE] EDIT-01
> "It compiles", "tests pass" or "it works" only count if a tool said so.
